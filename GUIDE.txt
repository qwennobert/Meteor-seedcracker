===============================================================================
  SEED MINER - Guide
  Meteor Client addon for Minecraft 1.21.11
===============================================================================

Seed Miner predicts where ores are from the world seed (e.g. diamonds or
ancient debris) and lets Baritone mine them automatically. Everything is
configured in the Meteor GUI.

Meant for your own server or singleplayer. On other people's servers this is
cheating and will get you banned.


-------------------------------------------------------------------------------
 1. WHAT YOU NEED
-------------------------------------------------------------------------------

Put all of these into the "mods" folder of your Minecraft 1.21.11 instance:

  [x] Fabric Loader 0.18.2 or newer
  [x] Fabric API (for 1.21.11)
  [x] Meteor Client 1.21.11
  [x] SeedMapper 2.21.x                -> https://modrinth.com/mod/seedmapper
  [x] Baritone, Meteor build 1.21.11   -> https://maven.meteordev.org
                                          (without Baritone, ores are only
                                           highlighted, not mined)
  [x] seed-miner-<version>.jar         -> this addon (see section 2)

IMPORTANT - JAVA 23:
  SeedMapper needs Java 23 or newer on 1.21.11. With Java 21 the game will
  not start.
  Install Java e.g. from https://adoptium.net/temurin/releases/ and select it
  for the instance in your launcher:
    - Vanilla launcher: Installations -> Edit -> More options
                        -> Java executable (on Windows "javaw.exe")
    - Prism Launcher:   Settings -> Java -> Java Runtime
    - Modrinth App:     Instance settings -> Java and memory


-------------------------------------------------------------------------------
 2. WHERE DO I GET THE JAR?
-------------------------------------------------------------------------------

  a) GitHub: repository -> "Releases" -> top release ("Latest")
     -> seed-miner-<version>.jar
     Every build has its own version, e.g. 0.2.0+build.12, and is built
     automatically on every push. Delete the old jar from the mods folder
     before you add the new one.

  b) Build it yourself:
       ./gradlew build          (Windows: gradlew.bat build)
     The jar is then in build/libs/


-------------------------------------------------------------------------------
 3. QUICK START (5 STEPS)
-------------------------------------------------------------------------------

  1. Find the seed. On your own server, type in chat:
         /seed

  2. Enter the seed in SeedMapper:
         /sm:config Seed set <your-seed>
     Seed Miner picks it up automatically.

  3. Open the Meteor GUI: RIGHT SHIFT.
     Category "Seed Miner" -> module "seed-miner".

  4. Right-click the module to open its settings. Under "blocks", pick the
     ores you want (default: diamond + ancient debris).

  5. Left-click the module to enable it. Baritone now walks or digs to the
     nearest predicted ore.

  TIP: Bind a key to toggle the module right away (in the module settings,
  "Bind" at the top). That way you can stop it at any time.


-------------------------------------------------------------------------------
 4. WHERE DOES THE SEED COME FROM?
-------------------------------------------------------------------------------

Setting "seed-source":

  Auto (default)   If "manual-seed" is filled in, that seed is used.
                   Otherwise SeedMapper is asked.
  Manual           Only the seed from "manual-seed".
  SeedMapper       Only the seed from SeedMapper.

SeedMapper looks in this order:
  1. /sm:config Seed set <seed>           (one fixed seed)
  2. /sm:config SavedSeeds add <seed>     (seed saved per server, handy if
                                           you play on several servers)
  3. SeedMapper's online database

When the module starts, the chat shows e.g.:
  "Using seed 12345 from SeedMapper config."

Enable "large-biomes" if the world was created with the Large Biomes preset.
Otherwise the predictions are wrong.


-------------------------------------------------------------------------------
 5. ALL SETTINGS
-------------------------------------------------------------------------------

[Seed]
  seed-source         Auto / Manual / SeedMapper                 Default: Auto
  manual-seed         Seed as a number, or text like in the
                      world creation screen. Empty = seed from
                      SeedMapper.                                Default: empty
  large-biomes        World created with Large Biomes?           Default: off

[Targets] - what to look for
  blocks              Which ores. Possible: coal, copper, iron, gold,
                      redstone, lapis, diamond, emerald, raw iron/copper
                      block, nether gold, nether quartz, ancient debris.
                      Stone and deepslate variants count the same.
                                             Default: diamond, ancient debris
  ore-veins           Also large copper/iron veins (slower)      Default: off
  chunk-radius        How many chunks around you are scanned
                      (0-16)                                     Default: 4
  min-y / max-y       Height range, e.g. -64 to 16 for
                      diamonds                                   Default: -64 / 320
  follow-player       Keep scanning new chunks while you move    Default: on
  server-anti-xray    Many servers (e.g. Paper) hide ores with
                      anti-xray: hidden blocks are shown as fake
                      ores or fake stone. With this on, only
                      blocks that touch air are believed, which
                      anti-xray always shows truthfully. Turn it
                      off only on a server without anti-xray.    Default: on
  mine-seen-ores      Also mine ores of the selected types that
                      are visible within 5 blocks of you, even if
                      the prediction missed them. Ores you can
                      already see next to you are mined first, so
                      no vein is left half done.                 Default: on
  verify              Off     = take every prediction
                      SkipAir = drop positions that are actually
                                air (recommended)
                      Exact   = also drop positions that are not
                                the ore (with server-anti-xray only
                                blocks that touch air are checked)
                                                                 Default: SkipAir

[Mining] - how ores are mined
  auto-mine           Mine with Baritone. Off = highlight only.  Default: on
  max-distance        Max. horizontal distance to an ore         Default: 96
  vertical-cost       How much height differences count when
                      picking the next ore. Higher = prefer
                      staying on your level.                     Default: 2
  target-timeout      Skip an ore after this many seconds        Default: 90
  path-retries        Retries when Baritone can't find a path    Default: 2
  collect-drops       Walk to the drops of mined ores (diamonds,
                      raw iron, ...) before moving on, so none
                      are left behind                            Default: on
    collect-radius    How far away drops are collected (blocks)  Default: 6
    collect-timeout   Give up on a drop after this many seconds  Default: 8
  configure-baritone  Sets Baritone's allowBreak=true (needed!)
                      and the two options below. Restored when
                      the module is disabled.                    Default: on
    allow-place       Baritone may place blocks (bridges,
                      covering lava)                             Default: on
    allow-parkour     Baritone may jump over gaps                Default: off
  disable-when-done   Disable when no ores are left. Otherwise
                      it waits for new chunks.                   Default: off

[Auto Tool] - which tool is used
  The module picks the tool for every block Baritone breaks (Baritone's own
  tool switching is turned off while the module runs). Tools must be in the
  hotbar.

  auto-tool           On/off                                     Default: on
  fortune-only-on-ores
                      Ores (coal, copper, iron, gold, redstone,
                      lapis, diamond, emerald, nether gold,
                      quartz): the pickaxe with the highest
                      fortune. Everything else: the fastest tool
                      WITHOUT fortune, so the fortune pickaxe
                      only wears down on ores.                   Default: on
    fortune-fallback  If there is no other pickaxe, use the
                      fortune pickaxe for stone too. Off = the
                      module stops with a message.               Default: off
  min-durability      Don't use tools with less durability left
                      (percent), so they don't break.            Default: 5

  Tip: carry a fortune pickaxe AND a normal (e.g. efficiency) pickaxe in the
  hotbar. Turn off Meteor's own "Auto Tool" module while Seed Miner runs.

[Safety]
  min-health          Disable at this health or lower (0 = off)  Default: 8
  stop-when-full      Disable when the inventory is full         Default: on
  require-pickaxe     Disable when there is no pickaxe in the
                      hotbar                                     Default: on
  pause-near-players  Pause while other players are nearby       Default: off
    player-range      Distance for that                          Default: 32

[Anti-Detection] - mine less conspicuously
  The group starts collapsed. Click the "Anti-Detection" title to expand or
  collapse it. The options below the master switch only show while it is on.

  anti-detection      Master switch                              Default: off
  max-ores-per-minute Mine at most this many ores within 60
                      seconds. When the limit is reached, the
                      module waits (status "Waiting (rate limit,
                      Xs)"). 0 = no limit                        Default: 8
  random-pause        Wait a random time after each ore          Default: on
    pause-min         Shortest pause in seconds                  Default: 1.5
    pause-max         Longest pause in seconds                   Default: 6
  stone-detours       After an ore, sometimes mine a random
                      stone block nearby instead of heading
                      straight to the next ore                   Default: off
    detour-chance     Chance in percent per ore                  Default: 25
    detour-distance   How far away the stone may be              Default: 4

  Note: ores that Baritone mines on the way count towards the limit too.
  So if several ores are right next to each other, a minute can end up
  slightly over the limit.

[Render]
  render              Highlight predicted ores                   Default: on
  render-limit        Max. number of highlights (nearest first)  Default: 300
  shape-mode          Lines / Sides / Both                       Default: Both
  side-color          Fill color of the ores                     Default: light blue
  line-color          Line color of the ores                     Default: light blue
  target-color        Color of the current target                Default: red
  tracer              Line to the current target                 Default: on


-------------------------------------------------------------------------------
 6. MODULE PAGE, HUD AND COMMANDS
-------------------------------------------------------------------------------

Module page (right-click the module), at the top:
  - Seed and its source, current status
  - Counters: Predicted, Mined, Skipped, Invalid (wrong prediction)
  - Buttons:
      Rescan       recompute everything
      Skip target  skip the current ore
      Reset stats  reset the counters
  (The values are refreshed when the page is opened.)

HUD:
  Meteor GUI -> "HUD" tab -> add the "seed-miner" element.
  Shows the status and counters on screen.

Chat commands (Meteor's prefix is the dot):
  .seedminer                Show the status (with anti-detection on, also
                            how many ores were mined in the last minute)
  .seedminer seed <seed>    Set the manual seed
  .seedminer clear-seed     Clear the manual seed
                            (SeedMapper is used again)
  .seedminer rescan         Recompute everything
  .seedminer skip           Skip the current ore


-------------------------------------------------------------------------------
 7. TIPS
-------------------------------------------------------------------------------

  - Diamonds only: under "blocks" pick only diamond ore + deepslate diamond
    ore, min-y = -64, max-y = 16.
  - Ancient debris: enable it in the Nether, height e.g. 8 to 22.
    Bring fire resistance!
  - Bring a good pickaxe (Efficiency, Unbreaking, Mending) and food.
    Baritone does not eat on its own.
  - A few cobblestone blocks in the inventory help Baritone cover lava and
    build bridges.
  - Lots of failed targets? Lower "chunk-radius". The module then stays
    closer to loaded chunks, where "verify" filters out wrong predictions.


-------------------------------------------------------------------------------
 8. TROUBLESHOOTING
-------------------------------------------------------------------------------

Game does not start / "requires java >= 23"
  -> Switch the instance to Java 23 or newer (see section 1).

"No seed available"
  -> Run /sm:config Seed set <seed> or fill in "manual-seed".

Status "No ores in range"
  -> There are no (remaining) ores nearby. Increase "max-distance" or
     "chunk-radius", check the height range and "blocks", or move on a bit.

Lots of "Invalid"/"Skipped"
  -> Normal to some degree: the prediction doesn't know whether an ore
     touches a cave (Minecraft often doesn't generate it then). It is less
     accurate for coal, copper and emerald in particular.
  -> Wrong seed or "large-biomes" set wrong? Then nothing matches. Check the
     seed with /seed.
  -> Server on a different version than 1.21.11 (e.g. via ViaFabricPlus):
     the prediction won't match.

Ores are only highlighted, not mined
  -> Is Baritone (Meteor build) installed? Is "auto-mine" on?

Module disables itself with "Baritone was given another goal"
  -> You gave Baritone a different command (e.g. #mine, #goto).
     Just enable the module again.

Stopping the module
  -> Disable the module (key bind or click in the GUI). Baritone's "#stop"
     is not enough: the module simply gives Baritone the next ore.
